# 국회 요구자료 목록화 시스템

의정자료전자유통시스템에서 받은 **요구서 PDF**를 업로드하면 텍스트를 자동 추출(OCR 포함)하고,
문서번호·위원회·의원명·요구일자·제출기한·요구자료 목록을 파싱해 **엑셀 관리대장**으로 정리하는 Flask 웹 앱입니다.

## 주요 기능

- **PDF 텍스트 추출 2단계**
  - 1차: `pdfplumber`로 텍스트 레이어 추출 (전자유통시스템 요구서 대부분)
  - 2차: 텍스트 레이어가 없는 스캔본은 `tesseract` OCR(한국어)로 자동 대체
- **요구서 파싱**: 소관위원회, 요구일자, 제출기한, 요구서번호, 요구의원/기관, 정당, 지역구, 자료 요구내용, 요구자, 요구자 이메일 (PDF 줄바꿈으로 잘린 문장도 이어붙여 추출)
  - 본문에 없는 요구서번호·요구일자·요구의원은 파일명에서 채웁니다 (`0007999174_황정아의원_자료요구서_260921.pdf` →
    요구서번호 0007999174, 요구일자 2026-09-21, 요구의원 황정아). 의원명은 국회의원 현황 명단에 있는 이름만 인정하며,
    결과 화면에 '파일명' 표시가 붙습니다
  - 제출기한이 없는 요구서는 결과 화면에서 직접 입력하면 다운로드하는 엑셀에 반영됩니다 (비워 두면 다운로드 전에 확인)
- **첨부 한글파일(HWP·HWPX) 인식**: 공통요구자료처럼 질의 항목을 한글 파일로 받은 경우, 질의서 PDF와 함께 올리면
  첨부를 해당 질의서에 연결하고 첨부의 항목을 질의 내역으로 기록합니다 (아래 '첨부 한글파일 처리' 참고)
- **엑셀 관리대장 자동 생성·누적** (기관 '국회 요구자료' 관리대장 양식)
  - 새 관리대장 생성 또는 기존 관리대장의 마지막 기록 다음 행에 이어서 추가 (순번 이어 매김, 바로 위 행 서식 유지)
  - 요구서 1건 = 1행, 내용 칸은 `[제목]` 다음 줄부터 질의를 줄바꿈으로 기록
  - 이미 대장에 있는 요구서 번호는 다시 기록하지 않음 (같은 파일을 두 번 올려도 안전)
- **개인정보 비저장**: 업로드 파일은 처리 후 임시 폴더에서만 다뤄지며, 결과 엑셀은 일정 시간(30분) 후 자동 삭제

## 로컬 PC에서 실행하기 (권장)

### Windows

1. [python.org](https://www.python.org/downloads/)에서 Python 3.10 이상 설치
   (설치 화면에서 **"Add Python to PATH"** 반드시 체크)
2. 프로젝트 폴더의 **`start.bat`** 더블클릭
   - 처음 한 번은 패키지 설치로 1~2분 걸리고, 이후에는 바로 실행됩니다.
   - 서버가 뜨면 브라우저가 자동으로 열립니다 (`http://127.0.0.1:5000`).
3. **`바로가기.html`** 파일을 바탕화면에 복사해 두면, 더블클릭만으로 시스템에 접속할 수 있습니다.
   (서버가 꺼져 있으면 start.bat을 먼저 실행하라는 안내가 표시됩니다.)

### macOS / Linux / Raspberry Pi

```bash
./start.sh
```

### 수동 설치

```bash
pip install -r requirements.txt
python app.py            # http://localhost:5000 자동 접속

# OCR 도구 (스캔본 PDF 처리에 필요, 선택)
sudo apt install tesseract-ocr tesseract-ocr-kor poppler-utils
# Windows는 https://github.com/UB-Mannheim/tesseract/wiki 설치 후 한국어(kor) 언어팩 선택
```

OCR 도구가 없어도 텍스트 레이어가 있는 PDF는 정상 처리됩니다.
이 프로그램은 PC 전용입니다 — 서버는 127.0.0.1에서만 열리며, 같은 PC의 브라우저에서만 접속할 수 있습니다.

## 사용 방법

1. **새 관리대장 생성** 또는 **기존 엑셀 파일 사용**을 선택합니다.
2. 요구서 PDF(최대 5개)와 첨부 한글파일(최대 5개)을 드래그하거나 클릭해 선택합니다.
3. **파일 처리**를 누르면 결과 화면(분배안)이 열립니다. 질의별 담당 부서·담당자 초안을 확인·수정하고,
   **분장내역 출력**으로 부서별 작성 요청용 엑셀을 받은 뒤 **관리대장 다운로드**(또는 **대장에 저장**)를 누릅니다.
4. 다운로드한 엑셀을 다음 처리 때 다시 업로드하면 접수 내역이 누적됩니다.

### PC의 대장에 바로 저장 (기본)

관리대장 선택의 기본값은 **PC의 대장에 바로 저장**입니다.
대장 파일 경로를 한 번 넣어 두면(브라우저가 기억), 업로드·다운로드 없이 결과 화면의 **대장에 저장**으로 그 파일에 바로 이어 씁니다.
대장 파일을 직접 올려 처리하고 결과를 내려받는 방식(**대장 파일 올려서 처리**)도 그대로 쓸 수 있습니다.

- 저장할 때 대장 파일이 엑셀에서 닫혀 있어야 합니다 (열려 있으면 안내 후 저장하지 않음).
- 처리한 뒤에 대장이 바뀌었으면(엑셀에서 저장, 공유폴더에서 다른 사람이 수정) 덮어쓰지 않고 다시 처리하라고 안내합니다.
- 처리 전 원본은 같은 폴더에 `…_백업.xlsx`로 남깁니다.

> ⚠️ 엑셀 관리대장의 열(Column) 구조를 임의로 변경하면 기능 오류가 발생할 수 있습니다.

## 분배안 (질의별 담당 부서 초안)

- **배분 방식**: 질의 문장 → 업무 카테고리(48개, 키워드 규칙) → 카테고리 안의 세부 키워드로 부서·업무 결정
  (없으면 기본 담당). 문장으로 정하지 못한 질의는 **확인 필요**로 표시해 기획실에 둡니다 (`extractor/assign.py`).
- 공통요구자료 첨부의 기관 유형 섹션 중 공통·〈연구기관〉·〈공공기관〉만 배분하고 나머지는 해당없음으로 둡니다.
  같은 요구서 안의 똑같은 질의는 한 번만 보여 줍니다.
- 부서는 **본부별**(기획본부 · 행정본부 · 정책전략본부 · 감사부 · 정보화전략센터 · 그 밖의 부서)로 묶고 본부마다 색으로 구분합니다.
- 화면에서 질의마다 **부서 → 그 부서원 중 담당자**를 고를 수 있고, **기제출** 체크 시 분장내역에 기제출로 표시됩니다.
  질의별 수정은 그 브라우저에만 저장됩니다.
- **이전 질의(기제출 자료 후보)**: 올린 대장에 쌓인 질의와 새 질의를 비교해 가까운 이전 질의를 보여 줍니다
  (`extractor/history.py`). 글자가 같으면 '동일', 기간·연도 숫자만 다르면 '기간만 다름', 그 밖에는 유사도 35% 이상만
  '유사 n%'로 표시하고, 요구일자·의원·제목·제출일자를 함께 보여 줍니다. **기제출로 표시**를 누르면 기제출 체크와 출처가 남습니다.
- 제출기한이 비어 있는 요구서는 '필수'로 표시됩니다. 표에서 고친 접수일자·제출기한은 다운로드하는 대장에 반영됩니다.

### 업무 분장내역 출력

결과 화면의 **분장내역 출력**은 화면에서 최종 확인한 배분(바꾼 부서·담당자, 기제출 체크)을 그대로 엑셀로 내려받습니다
(`extractor/export.py`, 서버에 저장하지 않음). 내려받을 때 그 배분을 결과 대장의 '배분 이력'에도 남깁니다.

- **분장내역**: 부서 · 담당자 · 요구서 번호 · 요구의원 · 요구 제목 · 질의 번호 · 질의 내용 · 제출기한 · 기제출 · 비고
  (본부·부서 순 → 요구서 → 질의 번호 순, 비고에 확인 필요·부서 변경·같은 질의·기제출 출처)
- **부서별 요약**: 부서 · 총괄담당자 · 질의 수 · 작성 요청 · 기제출 갈음 · 가장 이른 제출기한 · 담당자, 맨 아래 합계
- **해당없음**: 배분하지 않은 질의와 사유

### 마감 현황

업로드 화면의 **마감 현황만 보기**(새 파일 없이 대장만으로) 또는 결과 화면의 **마감 현황**에서
대장의 제출기한·제출일자로 기한 지남 · 오늘/내일 마감 · 이번 주 · 그 이후 · 기한 없음 · 제출 완료 건수와
미제출 요구서(기한 순), 부서별 미제출 질의 수('배분 이력' 기준)를 봅니다.
D-day는 사용하는 PC의 오늘 날짜로 계산하며, 대장의 **제출일자** 칸을 채우면 제출 완료로 바뀝니다 (`extractor/status.py`).

### 배분 정정 학습

고친 배분은 다음 배분에 반영됩니다 (`extractor/learning.py`). 배분 이력은 **대장 파일의 시트**에, 추가 규칙은 **앱 설정**에 쌓입니다.

- **'배분 이력' 시트**: 대장을 저장·다운로드할 때 질의마다 초안 부서와 확정 부서를 기록합니다.
  결과 화면 위쪽에 지금까지의 **배분 정확도**(초안 그대로 확정된 비율)가 나옵니다.
- **규칙 제안**: 같은 부서로 2번 이상 옮긴 질의에 공통으로 든 단어가 있고, 그 단어가 든 질의의 80% 이상이
  그 부서로 확정됐으면 "‘병가’가 들어간 질의를 감사부로 3번 옮겼습니다. 규칙으로 추가할까요?"라고 묻습니다.
  **규칙 추가**를 누르면 **설정의 배분 추가 규칙**에 저장되고, 이번 분배안과 다음 처리부터 기본 규칙보다 먼저 적용됩니다.
  설정 화면의 **배분 추가 규칙** 탭에서 직접 추가·수정·삭제할 수도 있습니다.
- **이전 정정 반영**: 예전에 부서를 고친 질의와 본문이 같거나 기간만 다른 질의는 고친 부서로 바로 배분합니다.

### 설정 (담당자 명단 · 업무 추가/제외 · 배분 추가 규칙)

담당자 이름은 코드나 관리대장에 두지 않고 **이 PC의 `data/settings.json`**에 보관합니다 (`extractor/settings.py`).
첫 화면 위쪽의 **설정**(또는 결과 화면의 **담당자 설정**)에서 고치며, 저장하면 앱을 다시 시작하지 않아도 다음 파일 처리부터 반영됩니다.
결과 화면에서 설정을 열었다면 저장 후 결과 화면으로 돌아오면 담당자 목록이 자동으로 다시 채워집니다.

- **탭**: ① 부서별 담당자(총괄담당자 · 업무 담당자 · 그 밖의 부서원) ② 업무 추가·제외 ③ 배분 추가 규칙 ④ 가져오기·백업
- **저장·백업**: 임시 파일에 쓴 뒤 바꿔 끼워 저장하므로 저장 중 꺼져도 파일이 깨지지 않습니다. 저장할 때마다 직전 설정을
  `data/backup/settings_YYMMDD_HHMMSS.json`으로 남기며(최근 20개), **가져오기·백업** 탭에서 이전 설정으로 되돌릴 수 있습니다.
- **기존 대장에서 가져오기**: 예전처럼 관리대장의 '부서별 담당자'·'배분 추가 규칙' 시트에 명단이 있으면 그 대장을 골라 설정으로
  가져옵니다 (덮어쓰기 전에 내용 확인). 설정이 없는 처음 실행에는 설정 화면에 이 안내가 나옵니다.
- **엑셀로 내보내기**: 현재 설정을 같은 시트 양식(본부 · 부서 · 구분 · 업무 · 담당자 · 키워드)으로 받아 인수인계에 씁니다.
- `data/` 폴더는 실명이 들어 있으므로 git에 올리지 않습니다(`.gitignore`). PC를 옮길 때는 이 폴더를 복사하거나 내보내기/가져오기를 쓰세요.
- **업무 제외**: 업무 이름 옆 ×를 누르면 그 업무로는 더 이상 배분하지 않습니다 (일회성 질의에서 생긴 업무 등).
  그 업무에 걸리던 질의는 같은 카테고리의 다음 업무나 기본 담당으로 가고, 갈 곳이 없으면 '확인 필요'로 기획실에 둡니다.
  '제외한 업무'에서 **되살리기**로 되돌릴 수 있습니다.
- **업무 추가**: 부서마다 **+ 업무 추가**로 업무 이름·키워드·담당자를 넣으면, 질의에 키워드가 있을 때 기본 규칙보다 먼저
  그 부서·업무로 배분합니다. 키워드 없이 추가하면 담당자 목록에만 쓰입니다.
- 추가·제외한 업무는 **다음 처리부터** 배분에 반영됩니다 (이미 만든 분배안은 화면에서 부서를 직접 바꿔 주세요).

## 관리대장 양식

1행 제목(`2026년도 국회 요구자료`), 3행 머리글, 4행부터 요구서 1건 = 1행입니다.

| 순번 | 요구서 번호 | 접수일자 | 제출기한 | 소속 | 의원명 | 비서관 | 자료요구서 제목 및 내용 | 제출일자 | 비고 |
|------|------------|---------|---------|------|--------|--------|------------------------|---------|------|

- 제출일자는 직접 관리하는 항목이라 비워 둡니다. 비고에는 첨부 한글파일의 제출 안내(※ 제출기한·제출방법 등)가 적힙니다.
- 소속(정당)은 제22대 국회의원 명단(`extractor/data/assembly_members.csv`)에서 의원명으로 찾아 적습니다.
- 기존 대장은 위쪽 10행 안에서 머리글 행을 찾아 열 순서를 검증합니다 (머리글의 띄어쓰기 차이는 허용).
  순번만 미리 매겨 둔 빈 행은 기록으로 보지 않으므로, 서식을 미리 깔아 둔 대장도 그대로 쓸 수 있습니다.

### 첨부 한글파일 처리

- **연결**: 첨부 파일명이 요구서번호(10자리)로 시작하면 같은 번호의 질의서에 연결합니다. 파일명에 번호가 없으면
  '첨부 파일 참고'류 질의서가 하나뿐일 때 그 질의서에 연결하고, 연결할 질의서가 없으면 파일명의 요구서번호만으로 따로 기록합니다.
- **항목 분리**: `1.` 최상위 항목 아래 `1)` 하위 항목이 여러 개면 하위 항목마다 한 줄(`1-3) [상위 제목] 내용`)로 나눠 내용 칸에 적습니다.
  상위 제목의 기간 조건(예: 최근 6년간)이 각 행에 함께 남고, '관련 근거 별첨'·'자회사 포함 제출' 같은 조건성 하위 항목은 따로 나누지 않습니다.
- **제약**: 암호·배포용 문서는 읽을 수 없으니 일반 문서로 다시 저장해 올려 주세요. HWP의 표는 칸 내용이 순서대로 추출되며,
  표 구조가 중요하면 한글에서 HWPX로 저장해 올리는 것이 가장 정확합니다.

## 프로젝트 구조

```
├── app.py                 # Flask 앱 (라우팅, 업로드 처리)
├── extractor/
│   ├── pdf_text.py        # PDF 텍스트 추출 (pdfplumber → OCR 폴백)
│   ├── hwp_text.py        # 첨부 한글파일 텍스트 추출 (HWP 5.0 / HWPX)
│   ├── parser.py          # 요구서·첨부 항목 파싱 (정규식)
│   ├── ledger.py          # 엑셀 관리대장 생성·누적 (openpyxl)
│   ├── assign.py          # 질의별 담당 부서 배분 (카테고리 규칙 + 세부 배분표)
│   ├── settings.py        # 앱 설정 저장소 (data/settings.json — 명단·업무 추가/제외·추가 규칙, 백업)
│   ├── roster.py          # 부서별 담당자 명단 구조·시트 양식 (가져오기·내보내기용)
│   ├── history.py         # 이전 질의(기제출 자료 후보) 찾기
│   ├── learning.py        # 배분 정정 이력(대장의 '배분 이력' 시트)·규칙 제안
│   ├── status.py          # 마감 현황 (요구서별 기한·제출, 부서별 미제출 질의)
│   ├── export.py          # 업무 분장내역 엑셀 (분장내역·부서별 요약·해당없음)
│   └── board.py           # 결과 화면(분배안) 데이터 구성
├── templates/             # 업로드·결과 화면(index.html), 설정 화면(settings.html)
├── static/                # CSS, JS
└── tests/                 # pytest 테스트
```
