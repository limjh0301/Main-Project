# 국회 요구자료 목록화 시스템

의정자료전자유통시스템에서 받은 **요구서 PDF**를 업로드하면 텍스트를 자동 추출(OCR 포함)하고,
문서번호·위원회·의원명·요구일자·제출기한·요구자료 목록을 파싱해 **엑셀 관리대장**으로 정리하는 Flask 웹 앱입니다.

## 주요 기능

- **PDF 텍스트 추출 2단계**
  - 1차: `pdfplumber`로 텍스트 레이어 추출 (전자유통시스템 요구서 대부분)
  - 2차: 텍스트 레이어가 없는 스캔본은 `tesseract` OCR(한국어)로 자동 대체
- **요구서 파싱**: 소관위원회, 요구일자, 제출기한, 요구서번호, 요구의원/기관, 정당, 지역구, 자료 요구내용, 요구자, 요구자 이메일 (PDF 줄바꿈으로 잘린 문장도 이어붙여 추출)
- **첨부 한글파일(HWP·HWPX) 인식**: 공통요구자료처럼 질의 항목을 한글 파일로 받은 경우, 질의서 PDF와 함께 올리면
  첨부를 해당 질의서에 연결하고 항목마다 1행씩 기록합니다 (아래 '첨부 한글파일 처리' 참고)
- **엑셀 관리대장 자동 생성·누적**
  - 새 관리대장 생성 또는 기존 관리대장에 이어서 추가
  - 요구서 1건 = 1행으로 기록, 열 구조 검증으로 서식 오류 방지
- **개인정보 비저장**: 업로드 파일은 처리 후 임시 폴더에서만 다뤄지며, 결과 엑셀은 일정 시간(30분) 후 자동 삭제

## 로컬 PC에서 실행하기 (권장)

### Windows

1. [python.org](https://www.python.org/downloads/)에서 Python 3.10 이상 설치
   (설치 화면에서 **"Add Python to PATH"** 반드시 체크)
2. 프로젝트 폴더의 **`start.bat`** 더블클릭
   - 처음 한 번은 패키지 설치로 1~2분 걸리고, 이후에는 바로 실행됩니다.
   - 서버가 뜨면 브라우저가 자동으로 열립니다 (`http://127.0.0.1:5000`).
3. **`바로가기.html`** 파일을 바탕화면에 복사해 두면, 더블클릭만으로 시스템에 접속할 수 있습니다.
   (서버가 꺼져 있으면 start.bat을 먼저 실행하라는 안내가 표시됩니다.)

### macOS / Linux / Raspberry Pi

```bash
./start.sh
```

### 수동 설치

```bash
pip install -r requirements.txt
python app.py            # http://localhost:5000 자동 접속

# OCR 도구 (스캔본 PDF 처리에 필요, 선택)
sudo apt install tesseract-ocr tesseract-ocr-kor poppler-utils
# Windows는 https://github.com/UB-Mannheim/tesseract/wiki 설치 후 한국어(kor) 언어팩 선택
```

OCR 도구가 없어도 텍스트 레이어가 있는 PDF는 정상 처리됩니다.
라즈베리파이 등 경량 서버에서 systemd 서비스로 등록해 운영할 수 있습니다.

## 사용 방법

1. **새 관리대장 생성** 또는 **기존 엑셀 파일 사용**을 선택합니다.
2. 요구서 PDF(최대 5개)와 첨부 한글파일(최대 5개)을 드래그하거나 클릭해 선택합니다.
3. **파일 처리**를 누르면 추출 결과 미리보기와 함께 관리대장 엑셀을 다운로드할 수 있습니다.
4. 다운로드한 엑셀을 다음 처리 때 다시 업로드하면 접수 내역이 누적됩니다.

> ⚠️ 엑셀 관리대장의 열(Column) 구조를 임의로 변경하면 기능 오류가 발생할 수 있습니다.

## 관리대장 열 구조

| 요구서번호 | 소관위원회 | 요구일자 | 제출기한 | 요구의원/기관 | 정당 | 지역구 | 자료 요구내용 | 요구자 | 요구자 이메일 | 담당 부서 | 제출여부 | 비고/메모 |
|-----------|-----------|---------|---------|--------------|------|--------|--------------|--------|--------------|-----------|---------|----------|

앞 10개 열은 요구서에서 자동 추출되고, 뒤 3개 열(담당 부서·제출여부·비고/메모)은 수동 관리 항목입니다.
첨부 한글파일의 제출 안내(※ 제출기한·제출방법 등)는 해당 요구서 첫 행의 비고/메모에 자동으로 적힙니다.

### 첨부 한글파일 처리

- **연결**: 첨부 파일명이 요구서번호(10자리)로 시작하면 같은 번호의 질의서에 연결합니다. 파일명에 번호가 없으면
  '첨부 파일 참고'류 질의서가 하나뿐일 때 그 질의서에 연결하고, 연결할 질의서가 없으면 파일명의 요구서번호만으로 따로 기록합니다.
- **항목 분리**: `1.` 최상위 항목 아래 `1)` 하위 항목이 여러 개면 하위 항목마다 1행(`1-3) [상위 제목] 내용`)으로 나눕니다.
  상위 제목의 기간 조건(예: 최근 6년간)이 각 행에 함께 남고, '관련 근거 별첨'·'자회사 포함 제출' 같은 조건성 하위 항목은 따로 나누지 않습니다.
- **제약**: 암호·배포용 문서는 읽을 수 없으니 일반 문서로 다시 저장해 올려 주세요. HWP의 표는 칸 내용이 순서대로 추출되며,
  표 구조가 중요하면 한글에서 HWPX로 저장해 올리는 것이 가장 정확합니다.

관리대장에는 **'국회의원 현황' 시트**(제22대 의원 명단)가 함께 들어가며, 소관위원회·정당·지역구 열은
요구의원 이름을 키로 한 VLOOKUP 수식으로 이 시트와 연동됩니다. 의원명을 수정하면 세 열이 자동으로
갱신되고, 명단에 없는 요구자(기관 등)는 요구서에서 파싱한 값으로 채워집니다.

## 프로젝트 구조

```
├── app.py                 # Flask 앱 (라우팅, 업로드 처리)
├── extractor/
│   ├── pdf_text.py        # PDF 텍스트 추출 (pdfplumber → OCR 폴백)
│   ├── hwp_text.py        # 첨부 한글파일 텍스트 추출 (HWP 5.0 / HWPX)
│   ├── parser.py          # 요구서·첨부 항목 파싱 (정규식)
│   └── ledger.py          # 엑셀 관리대장 생성·누적 (openpyxl)
├── templates/index.html   # 업로드 UI
├── static/                # CSS, JS
└── tests/                 # pytest 테스트
```
